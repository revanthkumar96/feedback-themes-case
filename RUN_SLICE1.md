# Slice 1: fixed-taxonomy classification contract

This slice proves one end-to-end path before taxonomy discovery or full-corpus
processing is added. It classifies the first ten reviews against a deliberately
small checked-in taxonomy, validates the model's evidence, derives both parent
tiers in ordinary code, and writes the rich result plus the required flat
projection.

The measured default is `openai/gpt-oss-20b` with medium reasoning. On the
ten-review slice, medium reasoning recovered an explicit secondary theme that
low reasoning missed and produced better self-contained evidence. The extra
latency and cost were immaterial at this scale.

## Requirements

- Python 3.11 or newer
- A Groq API key
- No third-party Python packages

From the repository root in PowerShell:

```powershell
$env:GROQ_API_KEY = "your-key"
python -m feedback_themes slice1
python score.py --pred out/flat.json
```

The API key is read only from the environment. It is never written to an output
file. Copy `.env.example` only as a reference; this program intentionally does
not load `.env` files.

## Outputs

- `out/results.json`: run metadata, measured tokens and latency, the exact
  taxonomy version, evidence-backed review assignments, and explicit
  `no_relevant_theme` abstentions.
- `out/flat.json`: the lossy projection consumed by `score.py`.

The model emits only `specific_theme_id` and a verbatim evidence span. Strategic
and midlevel parents are looked up from `data/slice1_taxonomy.json`; they are
never generated by the model.

## Measured verification

On the live ten-review run, the default completed in 3.497 seconds using 1,612
input tokens and 2,341 output tokens, for an estimated API cost of $0.000823.
The supplied scorer reported clean `ROWS` and `TREE` checks. Two consecutive
medium-reasoning runs produced identical assignment-ID sets for all ten reviews.

A manual review found 12 of 13 defensible assignments and no unsupported
assignment. The miss was the portal-usability aspect of "slow and old-fashioned";
the model assigned portal performance but not the separate usability theme. This
small, non-blind slice is a contract check rather than a reliable quality
estimate, so the prompt was not tuned further to force a perfect result.

## Useful options

```powershell
python -m feedback_themes slice1 --limit 5 --output-dir out
python -m feedback_themes slice1 --reasoning-effort low
python -m feedback_themes slice1 --help
```

Run the test suite without an API key:

```powershell
python -m unittest discover -s tests -v
```

This is not yet the final taxonomy or the full solution. The next slice should
address taxonomy discovery only after this provider and validation contract has
been exercised with a real Groq response.
